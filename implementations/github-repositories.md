* **[AutoSurvey Pipeline](https://github.com/hkust-nlp/AutoSurvey)**
  * **Description:** Official implementation of the AutoSurvey framework for automated survey generation.
  * **Key Features:** End-to-end pipeline covering arXiv paper retrieval, hierarchical outline generation, draft synthesis, and automated citation grounding.
  * **Research Relation:** Demonstrates how structured RAG systems generate comprehensive literature surveys while mitigating knowledge cutoff limits.

* **[FreshLLMs Benchmark & Search Augmentation](https://github.com/google-research/freshllms)**
  * **Description:** Official code repository for FreshQA and search-augmented LLM prompting methods.
  * **Key Features:** Includes the FreshQA evaluation suite and reference implementations for integrating search engine APIs into LLM generation workflows.
  * **Research Relation:** Benchmarks and mitigates temporal staleness and knowledge cutoff limitations in dynamic question answering.

* **[RealTime QA Pipeline](https://github.com/realtimeqa/realtimeqa)**
  * **Description:** System repository for the weekly updated RealTime QA benchmark framework.
  * **Key Features:** Data generation scripts, live evaluation pipelines, and baseline search-augmented model evaluation tools.
  * **Research Relation:** Measures how effectively non-parametric search integration bridges the gap between static model weights and current events.

* **[StreamingQA Evaluation Benchmark](https://github.com/google-research/language/tree/master/language/streamingqa)**
  * **Description:** Benchmark dataset and evaluation code tracking knowledge adaptation over time.
  * **Key Features:** Chronologically structured news QA datasets paired with continuous model evaluation pipelines.
  * **Research Relation:** Evaluates continual model updating, temporal adaptation, and long-term memory drift in language models.

* **[LangChain RAG Architecture Framework](https://github.com/langchain-ai/langchain)**
  * **Description:** Popular open-source framework for building context-aware, retrieval-augmented LLM applications.
  * **Key Features:** Pre-built modules for document chunking, vector database indexing, web search retrieval, and grounded text generation.
  * **Research Relation:** Serves as the foundational software stack for implementing RAG-based literature synthesis tools and external citation checkers.
